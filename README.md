"### Опис проєкту
Практична робота присвячена практичному вивченню архітектури протоколу HTTP/HTTPS, виконанню базових CRUD-операцій за допомогою клієнта Postman та консольної утиліти curl. У рамках роботи також досліджено:
- Механізми діагностики серверних статусів і кодів помилок.
- Профілювання мережевих таймінгів з'єднання (DNS, TCP, TLS Handshake, TTFB).
- Життєвий цикл і роботу з Cookie Jar, а також заголовки безпеки (HttpOnly, Secure, SameSite).
- Симуляцію крос-доменних запитів за допомогою CORS Preflight (методом OPTIONS).

### Інструкція запуску та перевірки
1. Консольні запити (curl): Використовуйте термінал Windows PowerShell із підтримкою вбудованої утиліти curl.exe. Усі приклади команд та відповіді серверів з кодами 200 OK, 201 Created зафіксовані у звіті.
2. Колекція Postman: Імпортуйте файл колекції My Collection.postman_collection.json у ваш клієнт Postman для повторного тестування.
